This document is the archive index for the retired Adaptive Flywheel / `ring` system. It exists to make the historical material explicit and discoverable without letting those documents continue to act as the current source of truth for `dp-ring v2`.

## How To Read This Archive

- Use these documents only for history, migration context, or to understand old assumptions still present in the repository.
- Do not treat them as current governance for architecture, naming, routing, or API design.
- When a legacy document conflicts with [README.md](../../../README.md), [VALUE.md](../../../VALUE.md), [docs/v2/ARCHITECTURE.md](../../../docs/v2/ARCHITECTURE.md), or [docs/documentation-standards.md](../../../docs/documentation-standards.md), the current v2 documents win.
